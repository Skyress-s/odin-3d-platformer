# Running project
- Need to have odin lang installed. https://odin-lang.org/
- `odin run src/`

# Packaging project
There is a separate odin project in ./build_src/ that builds, packages and zips the project.
- Need to have odin lang installed. https://odin-lang.org/
- `odin run build_src/`
- Should take about 3s. Afterwards should have a new *.zip folder containing the game. Ready to be played and shared!

# Releases
In the ./releases/ folder there are some previously made windows builds that are ready to be player with levels. These are currently of a slightly older version of the game. But has some levels created by me and some others! (Builds 1-5 where used for first playtests)
